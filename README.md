# DM Group — лестницы и ограждения

Сайт-портфолио DM Group (Екатеринбург). React 19 + Vite + Tailwind 4, GSAP ScrollTrigger + Lenis, Three.js, компоненты React Bits.

```bash
npm ci
npm run dev      # http://127.0.0.1:5190
npm run build
```

Демо на GitHub Pages: `npm run deploy:pages` собирает сайт и отправляет сборку в ветку `gh-pages` (адрес внутри `/dm-group/`, закрыто от индексации, форма в демо-режиме). Для боевого хостинга — обычный `npm run build` и `public/lead.php` с `lead-config.php` уровнем выше корня сайта.

Сделано в [Orbient](https://orbient.pro).
